Hexo Bento Theme - 现代化的 Bento Grid 风格博客主题

Bento Theme 是一个基于 Bento Grid 设计理念的现代化 Hexo 博客主题。它采用简洁优雅的网格布局，专注于内容展示，适合用于个人作品集、技术博客或项目展示。

✨ 主要特性

Bento Theme 融合了现代 Web 设计的精华特性：

🎨 Bento Grid 布局

采用卡片式网格布局，将内容以模块化方式呈现，既美观又实用。每个区块都能独立展示不同类型的内容。

📱 完全响应式

无论在桌面、平板还是手机上，都能获得完美的浏览体验。主题使用流式布局和媒体查询，确保在各种设备上都能正常显示。

⚡ 极简高性能

  • 精简的代码结构，无冗余依赖
  • 优化的 CSS 和 JavaScript
  • 快速加载，提升用户体验

🎯 内容优先

设计理念围绕内容展开，让读者专注于你的文章和作品，而不是花哨的装饰。

🌈 高度可定制

通过配置文件轻松自定义颜色、布局、导航菜单等，打造独一无二的个人博客。
